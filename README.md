CodeAlpha Hotel Reservation System

About the Project

Hotel Reservation System is a Java-based application developed as part of the CodeAlpha Java Programming Internship.

The project is designed to manage hotel room reservations, including room details and booking-related operations.

Features

- View available hotel rooms
- Manage room reservation details
- Enter customer and booking information
- Manage reservation-related operations
- Display booking details

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Console-based Application

How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Open the main Java file.
4. Compile and run the program.
5. Follow the instructions displayed in the application.
